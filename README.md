# 바이킹이야기 (Viking Stories)

노르드인의 바다와 정착이 어렵게 느껴지는 어른을 위해, 한국어로 짧게 정리한 정적 사이트입니다. 영어 제목은 짧게 두고, 설명은 한국어로 씁니다. 사는 주소는 [viking-stories.vercel.app](https://viking-stories.vercel.app)입니다.

나두 — 나의 모든 일상을 AI와 함께

게르만이야기의 다음 이야기입니다. 앞의 시대는 [germanic-stories.vercel.app](https://germanic-stories.vercel.app)에 있습니다. 나두 역사·신화로 이어지는 자매 사이트는 나두신화, 일리아스이야기, 그리스이야기, 로마이야기, 게르만이야기, 바이킹이야기, 이집트이야기, 페르시아이야기, 더 초즌 · 성경, 철학이야기, 대한민국이야기, 나두연표, 나두 허브입니다.

북유럽 신화는 나두신화에 항목이 없어 이 사이트의 신화 페이지에 둡니다. 나두신화는 그리스·로마 신을 비교할 때만 잇습니다.

## 메뉴

- **홈** `/`
- **바이킹** `/who` — 노르드인, 바이킹이라는 말, 사회, 배, 룬, 생활, 여성, 교역
- **신화** `/myth` — 오딘, 토르, 로키, 프레이야, 발할라, 라그나로크, 이그드라실
- **지도** `/map` — 서쪽 바다, 동쪽 강, 남쪽 해안의 도식
- **연대기** `/chronicle`, `/chronicle/[slug]` — 793년 린디스판부터 1066년까지
- **인물** `/people`, `/people/[slug]`
- **관계도** `/family-tree` — 라그나르 전승, 덴마크, 노르망디, 웨섹스, 류리크, 북대서양
- **영화** `/films` — 실제 작품만. 불법 영상 링크 없음
- **출처** `/sources`

글의 꼴은 한 줄 요약, 핵심 세 가지, 펼치는 「조금만 더」입니다. 전설과 역사는 배지로 나눕니다.

## 개발

```bash
npm ci
npm run dev
npm run typecheck
npm run build
```

Next.js 15 (App Router) · React 19 · Tailwind CSS v4 · TypeScript. 페이지는 빌드 때 정적으로 생성됩니다.

콘텐츠는 `data/`에 있습니다. `NEXT_PUBLIC_SITE_URL`의 기본값은 `https://viking-stories.vercel.app`입니다.

## 적는 기준

중세 기록의 이름과 위치만 밝히고, 없는 인용문을 만들지 않습니다. 현대 책의 문장을 번역해 붙이지 않습니다. 영화 제목은 실제 공개 제목을 쓰고, 작품을 볼 수 있는 불법 사이트는 안내하지 않습니다. 넷플릭스 배지는 한국 카탈로그를 확인한 뒤에만 붙입니다.
